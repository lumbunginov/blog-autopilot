How to Use

Blog Autopilot workflow in Claude Code

📋 The Workflow

1

Configure Settings

Set your WordPress credentials and business knowledge base in this dashboard. Run /blog-autopilot setup to open it anytime.

2

Companion Mode / Queue

Run /blog-autopilot (no keyword) to enter Companion Mode. Claude monitors this dashboard queue and auto-processes any pending tasks.

3

Generate Batch Articles

Use Auto Generate on the Planning page or run /blog-autopilot generate to create multiple scheduled articles from one seed keyword.

4

Auto-publish to WordPress

Article is written, image generated, and posted to WordPress as a scheduled draft. Review in WP Admin before publishing.

💻 Commands

# Companion Mode — monitor queue & process tasks automatically /blog-autopilot # Check queue again without reopening browser /blog-autopilot monitor # Batch planner — natural language or structured input /blog-autopilot generate tips sewa HT --product "Sewa HT" --location Surabaya --count 3 --start 2026-04-20 --spacing 7 # Full pipeline: research → write → image → post (interactive) /blog-autopilot tips memilih sound system terbaik # Just generate article ideas (no writing) /blog-autopilot research tips memilih catering # Write article without posting /blog-autopilot write panduan memilih vendor wedding # Post an existing markdown file /blog-autopilot post ./articles/my-article.md # Repair missing/failed image on an existing post /blog-autopilot fix-image 11282 # Check config status /blog-autopilot status # Open this dashboard /blog-autopilot setup # Show all commands /blog-autopilot help

🤖 Companion Mode & Queue

Companion Mode turns Blog Autopilot into an autonomous agent that processes articles from this dashboard's queue:

  1. Run /blog-autopilot in Claude Code (no keyword)
  2. Claude starts the dashboard and checks the Planning queue
  3. Any pending tasks are processed automatically (write → image → post)
  4. Claude re-checks every 2 minutes via scheduled wake-up

Add tasks via Auto Generate or + Tambah Manual on the Planning page — they'll be picked up on the next cycle.

⚡ Generate Command

Use /blog-autopilot generate to plan and schedule a batch of articles without opening the dashboard:

# Natural language /blog-autopilot generate buatkan 3 artikel keyword tips sewa HT untuk produk Sewa HT di Surabaya mulai 20 April jeda 7 hari # Structured flags /blog-autopilot generate tips sewa proyektor --product "Sewa Proyektor" --location Malang --count 5 --start 2026-05-01 --spacing 5

Claude will show a confirmation summary before processing. Type ya to confirm, tidak to cancel, or edit [field] [value] to adjust.

🔑 WordPress Application Password

Blog Autopilot uses WordPress Application Passwords (not your login password). To create one:

  1. Go to WordPress Admin → Users → Your Profile
  2. Scroll down to "Application Passwords"
  3. Enter a name like "Blog Autopilot" and click Add New
  4. Copy the generated password (format: xxxx xxxx xxxx xxxx)
  5. Paste it in the WordPress settings above
